# Godot + GitHub Beginner Workshop 🎮
**Temple Game Development Club**

This is the starter template repository for Git & Godot workshop. You will use this repo to learn version control basics and build your first 2D game in Godot 4.

---

## Prerequisites

Before starting, make sure you have installed:
1. **[Godot Engine 4.x](https://godotengine.org/download)** (Standard 64-bit version)
2. A **[GitHub Account](https://github.com/)**
3. Optional **[GitHub Desktop](https://desktop.github.com/)** to navigate Git using GUI

---

## Setup Instructions

1. **Fork this repository** to your own GitHub account (click the **Fork** button at the top right of this page).
2. Use git clone or open **GitHub Desktop**, select **File > Clone Repository...**, and clone your forked repo to your local computer.
3. Open **Godot 4**, click **Import**, navigate to this cloned folder, and select `project.godot`.
